レビューの決まり

  1. 無料ですご依頼にも掲載にも、お金はかかりません。お金を受け取って書くレビューはしていません。
  2. 実際に思ったことを書きます良い点も悪い点も、ゲームを実際にプレイして感じた「ホンネ」をレポートさせて頂きます。
  3. 公開前の確認はしません内容の確認や直しのご依頼はお受けしません。
    ただし、発売日・値段・機種や事実と異なる記載につきましては、迅速に対応させていただきます。
  4. お受けできる件数には限りがございます少数開発チームのため、対応できる数に限りがある点はご容赦ください。
  5. 遊ぶ機種Windows の PC で遊べるゲームを中心にお受けします。ほかの機種はご相談ください。

依頼からレビューまで

  1. 01このフォームでご依頼
  2. 02受付のメールが届きます（自動）
  3. 03お受けする場合は、メールでご連絡し、キーやビルドの受け取り方をご相談します
  4. 04遊び込んでから、レビューを公開します。公開したらお知らせします
